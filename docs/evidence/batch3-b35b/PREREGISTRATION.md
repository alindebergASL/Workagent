## Custody, scoring and reproducibility

`evaluation/harness.py` verifies frozen source/input/oracle manifests, stages only explicit flat input files, rejects links/path traversal/hash drift/canary contamination, creates unique stores and append-only attempt journals, and starts actual product request construction in a no-network bwrap namespace. The product cannot see evaluator directories, repository-wide tests, credentials, host PostgreSQL or host procfs. This is transport/file-custody verification, not a general arbitrary-code sandbox replacement; actual compute uses the existing gVisor service separately.

The deterministic probe emits **receipts, not solutions**. They must never count as live task outputs or human-rated successes. Raw inputs, exact request/count-request bodies, source hashes, outputs, stdout/stderr, memory-channel projections, per-episode state manifests, failed attempts and interrupted runs remain evaluator-private. Public reports expose only hashes, counts and scope labels. The evaluator is a trusted operator on this host; 0700 alone is not isolation against a same-UID product with unrestricted host shell. The OS mount/network boundary is mandatory; a future network-enabled app worker must have an equivalently enforced filesystem/tool capability boundary before live use.

For live results, `scoring.freeze_packet` copies exact downloaded output bytes to opaque names without variant labels/timing/logs; bind the task-specific check list and tolerance, hash the packet, and freeze before scoring. A blind judge gets only the task, allowed source evidence, oracle and outputs. Never execute candidate code in the evaluator host; hidden code tests run in a separate confined evaluator job, after the product output freeze. No oracle feedback, scores or hidden tests flow back into the original trajectory. Content may reveal treatment; record suspected unblinding. Mechanical text checks alone return `not_scored`; manual usefulness judgment and all required/fatal checks are mandatory. Sign/freeze scores before revealing the variant mapping. The scorer is not the implementer in live trials; control specimens merely test plumbing.
