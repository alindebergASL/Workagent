## What works

Ordinary conversation selects bounded public GitHub discovery/read through the existing gateway, retains versioned sources, creates a saved issue/release brief and exports the actual bytes. The named public source is **psf/requests**. Native and Claude-owned web expose truthful connector receipts in the existing Tool activity/Files surfaces. No GitHub token, OAuth account, private repository, write endpoint, arbitrary schema activation, or executable README is introduced.

- `connectors/{base,github_read}.py` fixes GitHub API HTTPS hosts/paths and unauthenticated GET-only transport; existing retrieval isolation rejects redirects, private addresses and arbitrary URLs. Evidence remains untrusted inert text.
- Strict discovery pages are bounded to 1–5 and 1–20 items, with typed next-page/has-more/limit-reached data. No whole-repository totals are inferred. Discovery body excerpts stop at 2,000 characters per record with explicit omissions; complete raw API bytes are retained.
- README is pinned to commit `3c7baaa05ab4aa49cc819ce3a819d260de19c157`, Git blob `4e5c44555c02f127cd0cca2efa8b22716c78ee23`. Mutable issue/release versions use exact response hash, ETag and observation time, not invented immutable upstream versions.
- Current repository/processor/generation/expiry authorization is checked before/after I/O and on snapshot, file, memory, export and provider use. Migration 064 adds owner-installed append-only selective restrictions; immutable grants and historical receipts are not rewritten. No cross-call HTTP cache is introduced; retained receipt reuse remains scope-checked.
- `PublicConnectorConsent` is a typed future seam for account/resources/effects/processor/expiry/access generation, not activated OAuth or a private pilot.
