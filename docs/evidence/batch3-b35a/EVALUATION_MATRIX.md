The eight-row correction matrix is repeated with the same saved identities after a fresh interpreter and two independent restores from the pre-correction archive. Actual service restart/browser reattachment and native full-process journeys are separate evidence. Restore intentionally denies provider/tool execution rather than resuming old grants/balances. Current tombstones, revisions and permissions are replayed before runtime login; the resulting offline inspection branch is not a continuing authority replica.

## Scope qualifications (do not silently promote these tests)
- No vector store/embedding cache exists in this candidate. Exact lexical records, summaries, retained contexts, file/proposal/export graphs and source snapshots are exercised; no claim about an unimplemented vector index.
- Source/model/MCP strings are inert untrusted evidence; these controls prove that they cannot mint consent, grants, approval or execution calls. They do not measure model resistance to every possible prompt attack.
- Read-only remote descriptors are not authority; supported MCP tools/schema/processor are pinned, the stdio process is OS-confined and browser network is disallowed. This is not a claim that arbitrary remote servers obey read-only labels.
- No arbitrary external email/purchase implementation is exercised. Gateway mock-effect unknown outcomes, actual compute/delegate execution and connector reconciliation retain uncertainty without resend/refund.

## §9 report fields — every row
- Frozen candidate/tool/source: SOURCE_MANIFEST.json and compute pinned runtime; synthetic fixtures and public harnesses; standing build-mode authority, paid product cap0.
- Artifacts/downloads: client readback JSON, screenshots, actual preserved human files in outputs; tests bind exact exports/proposals and independent calculations.
- Initial/later outcomes: per-campaign results retain original failures; worker restart, service/client restart and restore readbacks separated. No empirical learning transfer claim.
- Effort/latency/resources: actions and campaign seconds recorded; actual human minutes and settled model-tool billing unavailable.
- Failed attempts/interventions: ATTEMPTS.md plus all campaign records; fixture repairs are not product passes retrospectively.
- Boundary denials: the literal safety mappings above and narrow review closure supplement.
- Blinded usefulness/manual edits/user preference: unmeasured; successor B3.5b prepares those trials. Human preservation is verified, not a preference judgment.
- Verdict: deterministic correction/forget/revoke/isolated-recovery mechanisms only. No paid/private trial, deployment, default merge or full Batch3/usefulness acceptance.
