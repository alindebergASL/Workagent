# Analyze intake
Read the selected records, not unrelated workspace files. Preserve the accepted goal.
For each unique case, test whether an owner OR a next action is missing. Count the union,
not the sum of overlapping missing-field counts. Show numerator, denominator, case IDs,
method and source revisions. Never invent rows or hardcode a fixture result.
Recommend one bounded experiment from the user's notes. Clearly label it proposed.
Make the checklist reusable: case ID, owner, next action, unresolved reason and review.
Keep protected human wording literally intact in a separate stable document block.
Use current private availability only for private suggestions; no calendar writes.
Retain source limitations, unknown time savings and lack of causal evidence.
Propose plan and checklist as distinct independently versioned artifacts.
Load references/method.md only when detailed method guidance is needed.
