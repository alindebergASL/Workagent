# Resume work
Read current assignment, accepted artifact revisions and unfinished action records.
Recheck source access generation, current grants, dispatch fence and remaining budget.
Recover the existing run binding. Reconcile an unknown submission before another attempt.
Never retry a non-idempotent write merely because an acknowledgement is absent.
Preserve intervening human saves and source versions. Propose against the current base.
Continue the smallest authorized step; distinguish saved work, proposals and unresolved effects.
